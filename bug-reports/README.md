# Bug Reports

Defectos encontrados durante las pruebas.

## Convención

Cada reporte debe incluir:

- ID
- Título
- Severidad
- Prioridad
- Ambiente
- Precondiciones
- Pasos para reproducir
- Resultado actual
- Resultado esperado
- Evidencia
- Estado

Los reportes se basarán en defectos reproducibles y documentados.
